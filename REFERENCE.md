# FreightAudit AI — design reference (working baseline)

No external brand artifact was supplied; these tokens are a deliberate product baseline, not sampled brand colors. Replace this file when real brand guidance arrives.

- **Canvas:** `#F5F6F3`, quiet warm-neutral, used for page background only.
- **Surface:** `#FFFFFF`, documents, tables, and forms.
- **Ink:** `#1C2621`, primary text; secondary `#59665E`; muted `#7B877F`.
- **Accent:** `#176B4A`, restrained green for primary actions and links only.
- **Rule:** `#E1E6E1`, separators and borders.
- **Warning / error:** `#9A641D` / `#AA4038`, semantic only, never decoration.
- **Type:** system sans stack; 28/22/16/14/12 px scale. Monospace only for IDs and code-like references.
- **Layout:** left-aligned, compact operational tables, variable hierarchy by content importance, no ornamental gradients, emoji, decorative card-edge strips, fake meters, or motivational banners.
- **Logo:** wordmark only until a real mark is supplied.

## Do / don't
Do put evidence and math beside a finding; use real quantities; keep actions explicit; make empty/error/loading states useful. Don't imply automated certainty, hide provenance, or make suggested recovery look like booked savings.

## Correct example
A review table row shows invoice ID, carrier, one-line finding, billed and expected values, variance, and a link to the source page. The detail view explains the exact rule, formula, contract version, and user decision.
